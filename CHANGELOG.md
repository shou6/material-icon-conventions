# Change Log

All notable changes to this extension are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0]

### Added

- Test helper files with the `.mjs`, `.cjs`, `.mts`, and `.cts` extensions: `*.mock.*`, `*.mocks.*`, `*.fixture.*`, `*.fixtures.*`, `*.stub.*`, `*.fake.*`, and `*.e2e.*`. Also `*.e2e.jsx`
- GitHub Copilot custom agent files (`*.agent.md`, and the former `*.chatmode.md`) use the `agent` icon
- Folders: `cronjob`, `cronjobs` (`job`), `dummy`, `dummies` (`mock`), `webhook`, `webhooks` (`api`), `mysql`, `mariadb`, `sqlite`, `mongodb`, `mongo`, `mssql`, `sqlserver` (`database`), and `chatmodes` (`robot`)

## [0.0.1]

Initial release.
